🚀 Support Bot — smart tech support system in Telegram!

✨ What is it?
A powerful Telegram bot for receiving and managing customer requests right in the messenger. No third-party CRMs — everything in one place!

🛠 How it works?
📩 Client clicks "Create ticket" → describes the problem + can attach a photo/screenshot
🎫 Bot assigns a unique ticket number: #0001, #0012 etc.
👀 Admin in /admin panel sees all new tickets and takes them into work
💬 Admin replies — the answer instantly goes to the client
✅ After fixing, ticket is closed as "Resolved"
⭐️ Client rates support from 1 to 5

🔥 Features:
🟢 Statuses: New / In Progress / Resolved
📋 My tickets — client always sees status
🔍 Search by number #0012 for admin
🖼 Photo support
📊 Quality rating + SQLite database
🛡️ Spam and nonsense protection
